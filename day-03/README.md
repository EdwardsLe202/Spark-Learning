# Ngày 03 — Cài đúng môi trường trước khi viết Spark

[Ngày trước](../day-02/README.md) · [Bắt đầu khóa](../BAT_DAU.md) · [Ngày sau](../day-04/README.md)

**Hôm nay chỉ cần làm được:** Có Python 3.11, Java 17, PySpark 3.5.7 trong môi trường của repo.

## Mở theo thứ tự này

1. Đọc [ly_thuyet.md](ly_thuyet.md), dừng tại ví dụ để tự dự đoán.
2. Mở [thuc_hanh.md](thuc_hanh.md) để xem đề bài; [bai_lam.py](bai_lam.py) đã có lời giải đầy đủ để chạy và đối chiếu.
3. Đối chiếu kết quả trong [bai_lam.py](bai_lam.py). Nếu cần, ghi giải thích bằng comment ngay cạnh code.

**Cần biết trước:** Đã đạt tiêu chí của [ngày 02](../day-02/README.md). Ngày này mới cài môi trường; không cần có sẵn Spark để bắt đầu.

## Nhịp 2–3 giờ

- 15 phút: nhắc lại ngày trước hoặc đọc bảng đầu vào.
- 40–50 phút: đọc lý thuyết và giải thích ví dụ.
- 50–70 phút: chạy, thay đổi nhỏ và tự viết bài.
- 15–30 phút: so kết quả, ghi lỗi và câu chưa hiểu.

Nếu hết giờ mà chưa hiểu, học tiếp bài này ở buổi sau. Số ngày là thứ tự học, không phải hạn phải chạy qua bài.

## Khi nào chuyển tiếp?

Chạy lại bằng uv run ở terminal mới vẫn hiện đúng ba phiên bản, không cần cài mọi công cụ trong bản tham khảo.

Chưa tự làm được thì mở gợi ý ở cuối bài thực hành, thử lại một lần. Khi cần hỏi: “Tôi ở ngày 03, mục ..., đầu vào ..., tôi nghĩ kết quả là ..., nhưng chạy ra ...”.

## Bài làm đã hoàn thiện

In phiên bản và interpreter thực tế; kiểm tra Python 3.11, PySpark 3.5.7, Java 17 và môi trường Python riêng.

Chạy từ gốc repo: `uv run python scripts/run_day.py 03`. Các câu trả lời và giải thích nằm ngay trong bài làm.
